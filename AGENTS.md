glossary and resolving the locale's special scenes. Record untested in-game
rendering as unverified and defer CrossOver, installation, and visual checks

work that depends on that mechanism. Apply this decision to every new Protogen
locale without asking again.

checkpoint using the queue command documented in `localization/STATUS.md`.
